# Portuguese words for dev/english_check.py (m2:DT17, Phase 1 of mission 2).
#
# Words are compared after splitting identifiers (snake_case, kebab-case, camelCase,
# SCREAMING_CASE) and comment text into words, lowercased and without accents
# ("versão" -> "versao"). Any letter outside ASCII already flags by itself.
#
# [stems]     a word that starts with the stem flags (cofr -> cofre, cofres).
#             Each stem was checked against /usr/share/dict/{american,british}-english
#             and the identifiers of ~29k Rust/JS files from crates.io and npm: no
#             English word starts with it.
# [words]     the exact word flags. Built from the Portuguese words of the repository
#             (Brazilian dictionary minus the English ones, minus words common in
#             English code), plus Portuguese words that are also English
#             (nome, pasta, mascara, motor...) and neologisms of the code (pendrive,
#             cripto, autoteste...).
# [function]  Portuguese function words that are not English. In an identifier, one
#             of them as a segment flags (cofre_de_teste, para_o_protocolo). In a
#             comment, a sentence flags when it has two or more of these, or one of
#             these plus one [ambiguous].
# [ambiguous] short words that are also English, abbreviations or domains
#             ("a", "do", "no", "com" in example.com, "sal"). They never flag alone,
#             only together with a [function] word in the same comment sentence.
#
# A Svelte event prop is "on" + verb (onfechar, ontravado): the checker removes the
# leading "on" before looking the rest up.
