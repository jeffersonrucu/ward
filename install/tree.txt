# Tree of `make install` (Phase 51; D18 revised by D46/D47). One line per path,
# relative to DESTDIR (or to /): kind, mode, owner, group, path and origin.
#
# Kinds:
#   D  common system dir: created 0755 root:root if missing; never deleted. If it
#      already exists, it must be a real dir (no link), owned by root and not writable by
#      group and others.
#   d  Ward dir: created 0755 root:root; `make uninstall` deletes it if it ends up empty.
#   f  Ward file: installed with the mode, owner and group of the line (written to a
#      temporary file in the same dir and swapped by `rename`); uninstall deletes it.
#
# File origins:
#   bin:<name>  release artifact (BIN_WARD, BIN_WARDD, BIN_APP, BIN_NM), verified (ELF,
#               no `test-mode` mark; D7, D63) before any change;
#   src:<file>  file of this repository, copied as is;
#   crx         the extension package (EXTENSION_CRX), verified by `crx.py`;
#   gen:<name>  generated by install.sh: from the extension id and version, or the
#               apport list (`apport_list` of dump.sh, Phase 51c).
#
# Phase 51c: the apport and systemd-coredump dirs are common (D): the install creates
# them even without apport or systemd-coredump on the system, so they hold if one of
# them is installed later; uninstall only removes the Ward files. apport 2.28 reads both
# dirs (report-ignore and the old name blacklist.d); earlier ones, only the old one.
#
