# Árvore do `make install` (Fase 51; D18 revista por D46/D47). Uma linha por caminho,
# relativo a DESTDIR (ou a /): tipo, modo, dono, grupo, caminho e origem.
#
# Tipos:
#   D  pasta comum do sistema: criada 0755 root:root se faltar; nunca apagada. Se já
#      existe, tem de ser pasta de verdade (sem link), do root e sem escrita para grupo
#      e outros.
#   d  pasta do Ward: criada 0755 root:root; o `make uninstall` a apaga se ficar vazia.
#   f  arquivo do Ward: instalado com o modo, o dono e o grupo da linha (gravado num
#      temporário da mesma pasta e trocado por `rename`); o uninstall apaga.
#
# Origens dos arquivos:
#   bin:<nome>  artefato de release (BIN_WARD, BIN_WARDD, BIN_APP, BIN_NM), conferido
#               (ELF, sem marca de `test-mode`; D7, D63) antes de qualquer mudança;
#   src:<arq>   arquivo deste repositório, copiado como está;
#   crx         o pacote da extensão (EXTENSION_CRX), conferido pelo `crx.py`;
#   ger:<nome>  gerado pelo install.sh: a partir do id e da versão da extensão, ou a
#               lista do apport (`lista_apport` de dump.sh, Fase 51c).
#
# Fase 51c: as pastas do apport e do systemd-coredump são comuns (D): a instalação as
# cria mesmo sem o apport ou o systemd-coredump no sistema, para valerem se um deles
# for instalado depois; o uninstall tira só os arquivos do Ward. O apport 2.28 lê as
# duas pastas (report-ignore e o nome antigo blacklist.d); os anteriores, só a antiga.
#
# Nesta lista ficam exatamente os caminhos que o V9.1 confere (`make test-install`).
